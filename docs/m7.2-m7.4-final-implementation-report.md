## C. Milestone M7.3 — Docker Architecture & Multi-Stage Builds

### 1. Server & Worker Container (`reviewlens-server`)

Defined in [`Dockerfile`](file:///C:/Users/rites/Projects/reviewlens/Dockerfile):

- **Base OS:** `node:24-bookworm-slim` (pinned digest). Debian Bookworm includes OpenSSL 3.x, which is strictly required for the Prisma PSL schema engine (`schema-engine-debian-openssl-3.0.x`).
- **Workspace Dependency Resolution:** To handle monorepo internal dependencies (`@reviewlens/api` depends on `@reviewlens/core`), all package manifests are copied first, `npm ci` installs workspace symlinks, `@reviewlens/core` is compiled with `tsc`, and Prisma Client is generated before compiling `apps/api`.
- **Runtime Optimization:** The runner stage uses `npm ci --omit=dev`, copies compiled JavaScript dist outputs and Prisma schema files, and sets the unprivileged runtime user `USER node`.
- **Image Metrics:** Uncompressed disk usage: 1.09 GB; Content size: **243 MB**.
- **Security Audit:** Layers inspected via `docker history reviewlens-server:test`. Zero `.env` files, `.pem` files, or secrets are baked into any layer.

Defined in [`Dockerfile.web`](file:///C:/Users/rites/Projects/reviewlens/Dockerfile.web) and [`apps/web/nginx.conf`](file:///C:/Users/rites/Projects/reviewlens/apps/web/nginx.conf):

- **Builder Stage:** Node 24 slim compiling React 19 / Vite 8 with `VITE_BASE_PATH=/reviewlens/`.
- **Runner Stage:** `nginx:1.27-alpine` serving the static bundle.

## E. Milestone M7.4 — Azure VM Host Architecture & Resource Isolation

### 1. Swap Space Provisioning

The Azure VM (`Standard_B2ls_v2`, 2 vCPU, 3855 MiB RAM) initially had 0 MB of swap. To eliminate OOM risks when running three distinct applications:

- Provisioned a **2 GB dedicated swapfile** at `/swapfile`:
  ```bash
  sudo fallocate -l 2G /swapfile
  sudo chmod 600 /swapfile
  sudo mkswap /swapfile
  sudo swapon /swapfile
  ```
- Persisted in `/etc/fstab`:
  ```text
  /swapfile none swap sw 0 0
  ```

## F. Milestone M7.4 — Nginx Routing, Path Isolation & HTTPS Verification

### 1. Nginx Subpath Configuration

Deployed an isolated snippet at `/etc/nginx/snippets/reviewlens.conf`:

```nginx
# ReviewLens Isolated Configuration Snippet

# Redirect /reviewlens to /reviewlens/
location = /reviewlens {
    return 301 /reviewlens/;
}

# ReviewLens API Reverse Proxy
location ^~ /reviewlens/api/ {
    proxy_pass http://127.0.0.1:3001/api/;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";

    proxy_connect_timeout 60s;
    proxy_send_timeout 60s;
    proxy_read_timeout 60s;
}

# ReviewLens Frontend Reverse Proxy
location ^~ /reviewlens/ {
    proxy_pass http://127.0.0.1:3000/reviewlens/;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;

    proxy_connect_timeout 60s;
    proxy_send_timeout 60s;
    proxy_read_timeout 60s;
}
```
